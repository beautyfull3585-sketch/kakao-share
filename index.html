0 / 200자 (카카오 공유 글자 수 제한)

보낼 이미지 (선택)

5MB 이하 이미지 1장. 글과 함께 사진으로 보내져요.

  1. 버튼을 누르면 휴대폰 공유 화면이 떠요. 거기서 카카오톡을 골라요.
  2. 카톡에서 거래처를 여러 명 체크하고 확인을 누르면 글과 사진이 일반 메시지로 가요.
  1. PC 카톡에서 나와의 채팅을 열고, 복사한 글(사진)을 Ctrl+V로 붙여넣어 보내요.
  2. 보낸 말풍선에 마우스 오른쪽 클릭 → 전달을 눌러요.
  3. 오른쪽 이번에 보낼 곳의 거래처를 검색해 체크하고 확인. 사진도 같은 방법으로 전달해요.
